int n = Integer.parseInt(in.nextLine());int len = s.length();char[] chars = s.toCharArray();reverseString(chars, 0, len - 1);reverseString(chars, 0, n - 1);reverseString(chars, n, len - 1);while (start < end) {  chars[start] ^= chars[end];  chars[end] ^= chars[start];  chars[start] ^= chars[end];  start++; end--;}System.out.println(chars);
三次反转的结果：reverse(s) → reverse(s[0..n-1]) → reverse(s[n..len-1])，最终得到右旋后的字符串。
