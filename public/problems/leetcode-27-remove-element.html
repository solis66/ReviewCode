看清 slowIndex（写指针）与 fastIndex（读指针）在每一步如何移动，以及数组被原地覆盖的过程。

Java 代码 · 执行位置 快慢指针


      


      

        
核心不变量

        
    
          
  • [0, slowIndex) 是「已保留区间」：里面的元素一定 ≠ val，永远不会被再改动。
    • 
          
  • slowIndex 同时有两层含义：① 下一个要写入的位置；② 已保留元素的个数。
    • 
          
  • fastIndex 只负责往下扫描，不回头；遇到 val 就跳过，遇到非 val 就"搬运"到 slowIndex 处。
    • 
          
  • 被跳过的 val 并不会真的被删掉，只是被后面的元素覆盖；所以题目要求返回 slowIndex，只取前 slowIndex 个元素。
    • 
          
  • 每个元素最多被读取一次、写入一次 → 时间 O(n)，只用两个变量 → 空间 O(1)。
