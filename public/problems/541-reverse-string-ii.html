char[] ch = s.toCharArray();for (int i = 0; i < ch.length; i += 2 * k) {  int start = i;  int end = Math.min(ch.length - 1, start + k - 1);  while (start < end) {    char temp = ch[start];    ch[start] = ch[end];    ch[end] = temp;    start++; end--;  }}return new String(ch);
每轮外层循环跳过 2k 个字符，只反转当前段的前 k 个字符。
