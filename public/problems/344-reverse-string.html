344. 反转字符串 · 双指针（Java）

看清 i 与 j 如何相向夹逼，以及 temp 在交换字符时扮演的 中转站 角色 —— 少了它，字符就会被覆盖丢失。

Java 代码 · 执行位置 双指针


      


      

        
核心不变量

        
    
          
  • [0, i) 与 (j, n-1] 是「已就位区间」：这些字符已经落在最终位置上，永远不会再被改动。
    • 
          
  • i 指向待处理区间的最左，j 指向最右；每完成一轮交换，区间 [i, j] 两边各缩一格，所以最多执行 ⌊n/2⌋ 轮。
    • 
          
  • temp 是交换的中转站：Java 里 s[i] = s[j] 会直接把 s[i] 冲掉，所以必须先把 s[i] 存进 temp，再回填到 s[j]——三行代码的顺序不能颠倒。
    • 
          
  • 循环条件是 i < j 而不是 i <= j：长度为奇数时最后 i == j，中间那个字符本来就在正确位置，交换反而多余。
    • 
          
  • 只用 i、j、temp 三个变量 → 额外空间 O(1)；每个字符最多被读写一次 → 时间 O(n)，而且是原地修改，不新开数组。
